Ajuste de Undervolt e Eficiência Energética (Arch Linux)
Documentação do processo de configuração de undervolt utilizando o intel-undervolt em um sistema Arch Linux, visando a redução de temperatura e o aumento da autonomia da bateria.

⚠️ Aviso importante: Cada processador possui limites diferentes (a famosa "loteria do silício"). Copiar valores cegamente pode causar instabilidade, travamentos ou telas azuis/congelamentos. Teste sempre o seu próprio hardware!
